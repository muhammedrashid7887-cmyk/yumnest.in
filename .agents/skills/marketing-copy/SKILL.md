# Marketing Copy

## When to Use This Skill
- Writing landing page headlines and descriptions
- Creating product descriptions that communicate value
- Drafting email campaigns for launches or promotions
- Writing ad copy that drives action

## Workflow
1. Identify the audience: who are you writing for and what do they care about
2. Define the value proposition: what problem does this solve
3. Write the headline: clear, specific, benefit-focused
4. Write the body: expand on the headline with proof and details
5. Add a call to action: what should the reader do next
6. Review for clarity: would a non-technical person understand this
7. A/B test: create variations and measure which performs better

## Rules
- Lead with benefits, not features
- Use specific numbers and outcomes, not vague claims
- Write at an 8th-grade reading level for broad accessibility
- Include social proof: testimonials, case studies, or metrics
- One call to action per page — don't dilute the message
- Test with real users — don't assume you know what resonates
